# Agastya Research And Technologies — Website starter

This is a responsive, static HTML/CSS/JavaScript starter website for `agastyatechnologies.com`.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive styling and navy/teal/gold brand palette
- `script.js` — mobile navigation, year, and enquiry mailto behavior
- `favicon.svg` — simple temporary favicon/monogram

## Before publishing
1. Review all company descriptions and service claims. This starter intentionally avoids unverified certifications, client names, and performance claims.
2. Replace the temporary inline A monogram with the final approved Agastya logo if you have the original logo file.
3. Confirm the contact details and `info@agastyatechnologies.com` mailbox work.
4. The enquiry form opens the visitor's email application; it does not send/store messages by itself. A server-side form service would be a separate later choice.
5. Keep the Google Workspace MX, SPF, DKIM and DMARC DNS records intact when connecting the website domain.

## Local preview
Open `index.html` in a browser. For best testing, use a simple local web server, but the site has no build step or package dependencies.

## Hosting note
This is a static website and can be deployed to a static hosting service. The domain registration itself is not web hosting. Connect the custom domain only after choosing the hosting provider, and preserve email-related DNS records.
